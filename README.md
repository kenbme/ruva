# Ruva – Ruby Subset → Java Transpiler

**Ruva** is a project that transpiles a subset of the Ruby language into Java and allows it to run using a minimal runtime that implements operations, dynamic types, arrays, hashes, and boolean logic.

The project is composed of two components:

1. **Ruby → Java Transpiler**, written in Ruby and using the **official Ruby parser (Prism)**
2. **Java Runtime (Ruva)** that executes the generated code

---

## Ruby → Java Transpiler

The transpiler reads Ruby files (`.rb`), uses **Prism** to generate the AST, and emits a **`RuvaProgram.java`** file ready for compilation.

### Example Ruby (subset)

```ruby
a = 2 + 2
b = a * 3

if true
  puts b
end
```

### Generated Java code (`RuvaProgram.java`)

```java
RuvaObject a = Ruva.add(Ruva.int(2), Ruva.int(2));
RuvaObject b = Ruva.mul(a, Ruva.int(3));

if (Ruva.truthy(Ruva.ruvaTrue())) {
    Ruva.puts(b);
}
```

> All operations go through the **Ruva runtime**, ensuring dynamic typing and support for arrays, hashes, and booleans.

---

## Java Runtime (Ruva)

The runtime provides the necessary methods for the generated Java code to work correctly:

* `RuvaObject` – dynamic base type
* Arithmetic operations: `add`, `sub`, `mul`, `div`, `pow`
* Boolean logic: `ruva_true()`, `ruva_false()`
* Arrays and hashes
* I/O: `puts`, `gets`

## Minimal Maven Project Structure

```text
ruva-project/
 ├─ pom.xml
 └─ src/
     └─ main/
         └─ java/
             └─ com/ruva/
                 ├─ Ruva.java           # runtime
                 ├─ RuvaObject.java     # base type
                 └─ RuvaProgram.java    # generated by the Ruby transpiler
```

All Java files must use the **package `com.ruva`**.
